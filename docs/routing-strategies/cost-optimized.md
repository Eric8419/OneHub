# 成本优先（`cost-optimized`）

## 行为

在有有效、非负 `costPerMillionTokens` 的目标中，选择每百万 Token 成本最低的目标。没有成本数据的目标不会参与成本比较。

如果所有候选都没有有效成本配置，则回退到优先级策略。故障转移会先过滤失败目标，再重新比较剩余目标的成本。

## 适用场景

- 多个模型质量可接受，但价格差异明显。
- 希望把低成本目标作为默认出口，并保留高成本目标作为备用。

## 注意事项

成本字段是价格提示，不会估算本次请求的真实 Token 数，也不会自动从供应商账单系统同步价格。不同币种或不同计费维度应先统一换算。
