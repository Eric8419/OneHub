# 自动优选（`auto`）

## 行为

为每个候选计算综合分并选择最高者：

| 维度 | 权重 |
|---|---:|
| 上游健康 | 0.28 |
| 配额余量 | 0.18 |
| 成本 | 0.16 |
| 延迟 | 0.16 |
| 当前负载 | 0.12 |
| 上下文适配 | 0.10 |

目标级延迟优先于模型级延迟；没有历史数据的维度使用中性分。健康状态、并发数、成功后的延迟和目标身份都参与运行时评分。

## 适用场景

- 不想手工决定成本、速度和可靠性的权衡。
- 上游质量和负载会动态变化。

## 注意事项

自动优选是通用折中，不一定等于最低成本、最低延迟或最大余量。对单一目标明确优化时，使用对应的专用策略更容易解释和调试。
